Sandfort API reference

REST API version 0.1.0: 91 operations in 12 groups. Every operation except the health and status routes needs an API key sent as Authorization: Bearer. This list is the plain version of the interactive reference; the full specification is openapi.json.

health

  • GET /healthz - Healthz
  • GET /readyz - Readyz
  • GET /v1/status - Status

api-keys

  • GET /v1/api-keys - List Api Keys
  • POST /v1/api-keys - Create Api Key
  • DELETE /v1/api-keys/{key_id} - Revoke Api Key

audit

  • GET /v1/audit-events - List Audit Events
  • GET /v1/audit-events/export - Export Audit Events
  • GET /v1/audit-events/verify - Verify Audit Chain

auth

  • POST /v1/auth/sso/exchange - Exchange

image-builds

  • POST /v1/images/builds - Build Image
  • GET /v1/images/builds/{snapshot_id}/logs - Stream Build Logs

sandboxes

  • GET /v1/isolation - List Isolation
  • GET /v1/sandboxes - List Sandboxes
  • POST /v1/sandboxes - Create Sandbox
  • GET /v1/sandboxes/{sandbox_id} - Get Sandbox
  • DELETE /v1/sandboxes/{sandbox_id} - Delete Sandbox
  • PATCH /v1/sandboxes/{sandbox_id} - Update Sandbox
  • GET /v1/sandboxes/{sandbox_id}/logs - Stream Sandbox Logs
  • POST /v1/sandboxes/{sandbox_id}/preview-tokens - Mint Preview Token
  • POST /v1/sandboxes/{sandbox_id}/reset - Reset Sandbox
  • POST /v1/sandboxes/{sandbox_id}/resize - Resize Sandbox
  • POST /v1/sandboxes/{sandbox_id}/start - Start Sandbox
  • POST /v1/sandboxes/{sandbox_id}/stop - Stop Sandbox

jobs

  • GET /v1/jobs - List Jobs
  • GET /v1/jobs/{job_id} - Get Job

org

  • GET /v1/org/members - List Members
  • POST /v1/org/members - Create Member
  • DELETE /v1/org/members/{user_id} - Remove Member
  • PATCH /v1/org/members/{user_id} - Update Member
  • GET /v1/org/quota - Get Quota
  • PUT /v1/org/quota - Put Quota
  • GET /v1/org/quota/recount - Get Recount
  • GET /v1/org/usage - Get Usage

toolbox

  • GET /v1/sandboxes/{sandbox_id}/toolbox/code-contexts - List code contexts
  • POST /v1/sandboxes/{sandbox_id}/toolbox/code-contexts - Create a code context
  • DELETE /v1/sandboxes/{sandbox_id}/toolbox/code-contexts/{context_id} - Delete a code context
  • POST /v1/sandboxes/{sandbox_id}/toolbox/code-contexts/{context_id}/interrupt - Interrupt the running cell of a code context
  • POST /v1/sandboxes/{sandbox_id}/toolbox/code-contexts/{context_id}/run - Run a cell in a code context
  • POST /v1/sandboxes/{sandbox_id}/toolbox/code-contexts/{context_id}/run/stream - Run a cell in a code context and stream its output
  • POST /v1/sandboxes/{sandbox_id}/toolbox/fs/delete - Delete Path
  • GET /v1/sandboxes/{sandbox_id}/toolbox/fs/download - Download Path
  • HEAD /v1/sandboxes/{sandbox_id}/toolbox/fs/download - Download headers
  • GET /v1/sandboxes/{sandbox_id}/toolbox/fs/list - List Directory
  • POST /v1/sandboxes/{sandbox_id}/toolbox/fs/mkdir - Make Directory
  • POST /v1/sandboxes/{sandbox_id}/toolbox/fs/move - Move Path
  • GET /v1/sandboxes/{sandbox_id}/toolbox/fs/stat - Stat Path
  • PUT /v1/sandboxes/{sandbox_id}/toolbox/fs/upload - Upload File
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/add - Add Files
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/clone - Clone Repository
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/commit - Commit Changes
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/pull - Pull Changes
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/push - Push Changes
  • GET /v1/sandboxes/{sandbox_id}/toolbox/git/status - Repository Status
  • POST /v1/sandboxes/{sandbox_id}/toolbox/git/status - Repository Status By Body
  • POST /v1/sandboxes/{sandbox_id}/toolbox/process/code-run - Run Code
  • POST /v1/sandboxes/{sandbox_id}/toolbox/process/execute - Execute Command
  • GET /v1/sandboxes/{sandbox_id}/toolbox/process/sessions - List Sessions
  • POST /v1/sandboxes/{sandbox_id}/toolbox/process/sessions - Create Session
  • GET /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id} - Get Session
  • DELETE /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id} - Delete Session
  • POST /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id}/commands - Execute Command
  • GET /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id}/commands/{command_id} - Get Command
  • POST /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id}/commands/{command_id}/kill - Kill Command
  • GET /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id}/commands/{command_id}/logs - Get Command Logs
  • GET /v1/sandboxes/{sandbox_id}/toolbox/process/sessions/{session_id}/commands/{command_id}/logs/follow - Follow Command Logs
  • GET /v1/sandboxes/{sandbox_id}/toolbox/pty - List Ptys
  • POST /v1/sandboxes/{sandbox_id}/toolbox/pty - Create Pty
  • GET /v1/sandboxes/{sandbox_id}/toolbox/pty/{pty_id} - Get Pty
  • DELETE /v1/sandboxes/{sandbox_id}/toolbox/pty/{pty_id} - Close Pty
  • POST /v1/sandboxes/{sandbox_id}/toolbox/pty/{pty_id}/resize - Resize Pty

snapshots

  • GET /v1/snapshots - List Snapshots
  • POST /v1/snapshots - Register Snapshot
  • POST /v1/snapshots/from-sandbox - Create Snapshot From Sandbox
  • GET /v1/snapshots/{snapshot_id} - Get Snapshot
  • DELETE /v1/snapshots/{snapshot_id} - Delete Snapshot
  • GET /v1/snapshots/{snapshot_id}/export - Export Snapshot

volumes

  • GET /v1/volumes - List Volumes
  • POST /v1/volumes - Create Volume
  • GET /v1/volumes/{volume_id} - Get Volume
  • DELETE /v1/volumes/{volume_id} - Delete Volume
  • GET /v1/volumes/{volume_id}/export - Export Volume
  • POST /v1/volumes/{volume_id}/restore - Restore Volume

webhooks

  • GET /v1/webhooks - List Endpoints
  • POST /v1/webhooks - Create Endpoint
  • GET /v1/webhooks/{endpoint_id} - Get Endpoint
  • DELETE /v1/webhooks/{endpoint_id} - Delete Endpoint
  • PATCH /v1/webhooks/{endpoint_id} - Update Endpoint
  • GET /v1/webhooks/{endpoint_id}/deliveries - List Deliveries
  • GET /v1/webhooks/{endpoint_id}/deliveries/{delivery_id} - Get Delivery
  • POST /v1/webhooks/{endpoint_id}/deliveries/{delivery_id}/redeliver - Redeliver
